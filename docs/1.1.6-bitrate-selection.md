# 1.1.6 高码率流选择

## 已解决

- 同一清晰度存在多个 B 站 DASH 视频流时，默认按片源声明码率选择较高的一路；不再仅按编码兼容性和 CDN 线路排序。
- 新增“视频质量”选项：默认“高码率优先（推荐）”，可切换为“兼容优先”。选项同时作用于单视频、分 P 自动队列和列表下载。
- 文件大小预估改为使用实际会被选中的视频流，避免预估与下载结果不一致。

## 说明

- 本扩展只下载并封装 B 站提供的原始音视频流，不进行转码，不会虚构或提升不存在的码率。
- “1080P”和“1080P+”是不同清晰度档位；账号权限、视频片源和 B 站返回的可用流决定是否能选择“1080P+”。
- 若 Windows 属性页显示的码率与文件大小、时长明显矛盾，应使用 MediaInfo 或 ffprobe 复核容器元数据和真实流码率；仅凭该属性字段不能判断为低码率源。
